# AT_rainy-skills

一个通用的积木库：把自己真正会用的小 skill 攒在这里。

## 已收录

| Skill | 作用 |
|---|---|
| `transcript-organizer` | 把逐字稿、课堂笔记、会议记录整理成按「道 / 法 / 术 / 器」分层的整理稿 |

## 怎么用

把某个 skill 文件夹整个下载/复制到你的 skills 目录下即可，例如：

```
~/.newmax/skills/transcript-organizer/SKILL.md
```

结构约定：每个 skill 一个文件夹，里面必须有一个 `SKILL.md`，开头用 `name` 和 `description` 说明它是干什么的、什么时候触发。
